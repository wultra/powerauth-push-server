## [2.2.0] - 2026-07-20

### Added

- Added JSON structured logging foundation [(#1103)](https://github.com/wultra/powerauth-push-server/issues/1103)
- Added Artifact Signing documentation [(#1126)](https://github.com/wultra/powerauth-push-server/pull/1126)

- Updated Spring Boot to 4.0.7 [(#1149)](https://github.com/wultra/powerauth-push-server/issues/1149)
- Upgraded Docker base image to OpenJDK 25 [(#1140)](https://github.com/wultra/powerauth-push-server/issues/1140)
- Swapped Docker images to use Wultra base images for JRE and Liquibase [(#1158)](https://github.com/wultra/powerauth-push-server/issues/1158)
